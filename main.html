Wie funktioniert ein Tilger? Modellierung, Eigenformen und Auslegung

Autor / Dozent

Inhaltsverzeichnis

    Wie funktioniert ein Tilger?

    Ein Tilger (engl. Tuned Mass Damper, TMD) ist ein bewusst auf eine Zielschwingung abgestimmter Zusatzschwinger. Er reduziert die Antwortamplitude des Primärsystems in einem Frequenzbereich um die Abstimmung.

    Kernidee: Aus einem 1-DOF-System wird ein 2-DOF-System. Dadurch entstehen zwei Eigenfrequenzen (Frequenzaufspaltung) und dazwischen typischerweise eine Antiresonanz mit kleiner Primärantwort.

    Tilgermodell

    2-seitige Lagerung (Fest-/Loslager)

    Für definierte Randbedingungen wird die Struktur in Prüfständen häufig als Balken mit Fest-/Loslagerung realisiert. Der Tilger wird an einer Position mit großer modaler Auslenkung (Antiknoten) angebunden.

    Tilgerprüfstand

    Typischer Aufbau: Erreger (Shaker/Unwucht) → Struktur → Sensorik → Auswertung (FRF, Eigenfrequenzen, Dämpfung). Der Tilger wird in Masse, Steifigkeit und Dämpfung variiert.

    Eigenformen wiederholen

    \[ \left(\mathbf{K}-\omega^2\mathbf{M}\right)\mathbf{\varphi}=\mathbf{0} \]

    Eigenformen beschreiben die Schwingungsform. Für die Tilgerauslegung wird die Zielmode identifiziert und der Tilger auf deren Frequenz abgestimmt.

    Tilger demonstrieren

    1. Primärsystem ohne Tilger: Resonanzkurve aufnehmen.
    2. Tilger montieren: Frequenzaufspaltung (zwei Peaks) beobachten.
    3. Abstimmung variieren (\(k_2\)): Tal/Antiresonanz verschiebt sich.
    4. Dämpfung variieren (\(c_2\)): Peaks werden flacher, Bandbreite steigt.

    Tilger berechnen

    1. Zielmode bestimmen: \(\omega_t \approx \omega_n\).
    2. Massenverhältnis wählen: \(\mu = m_2/m_1\).
    3. Steifigkeit setzen: \(k_2 = m_2\,\omega_t^2\).
    4. Dämpfung setzen: \(c_2 = 2\,\zeta_2\,m_2\,\omega_t\).
    5. Verifikation: Simulation (FRF/Eigenwerte) und Messung (Prüfstand).

    1-Massen-Schwinger

    \[ m\ddot x + c\dot x + kx = F_0\sin(\omega t),\qquad \omega_0=\sqrt{\tfrac{k}{m}} \] \[ \frac{X(\omega)}{F_0/k}=\frac{1}{\sqrt{(1-r^2)^2+(2\zeta r)^2}},\qquad r=\frac{\omega}{\omega_0} \]

    3-Massen-Schwinger

    \[ \mathbf{M}\ddot{\mathbf{q}} + \mathbf{C}\dot{\mathbf{q}} + \mathbf{K}\mathbf{q} = \mathbf{f}(t) \]

    Vorgehen: Eigenformen bestimmen, Zielmode auswählen, Tilger modal auslegen, im 3-DOF- oder FE-Modell validieren.

    Kontinuumsschwinger

    \[ \rho A\,\ddot w(x,t) + EI\,w^{(4)}(x,t)=p(x,t) \]

    Modalansatz: \(w(x,t)=\sum_{n=1}^{\infty}\phi_n(x)\,q_n(t)\).
